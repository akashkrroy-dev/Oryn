# Project Instructions for Oryn

## General Guidelines
- Follow existing code conventions and patterns in the codebase
- Use TypeScript for all new code
- Prefer functional components with hooks over class components
- Use Clerk for authentication (already set up in the project)
- Keep responses concise and to the point
- Do not add comments unless explicitly requested

## Project Structure
- Next.js 13+ App Router (indicated by `app/` directory)
- Authentication routes under `app/(auth)/`
- Clerk integration for auth

## Commands
- Check package.json for available scripts
- Run lint/typecheck before committing changes

## Code Style
- No unnecessary comments
- Follow existing import/export patterns
- Use existing UI components and styling approaches
